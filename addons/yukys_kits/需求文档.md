## 功能明细

### FEAT-001 · 导表功能

- **状态**：✅
- **类型**：编辑器工具 + 运行时
- **优先级**：高

**需求背景 / 动机**

> 把策划在表格里维护的数据，按规则自动转成游戏可读的数据文件，避免手工维护 JSON。

**功能描述**

> 把「规定格式」的 CSV 表格导出为 JSON 数据文件，并在游戏内通过 `GameDB` 访问。

**功能点清单**

- [x] 插件目录下子目录 `data_tools`
- [x] Dock 界面：设置导入文件、导出路径、数据库路径，并监控/展示数据文件
- [x] 规定格式的表格转数据（CSV → JSON，含类型转换）
- [x] 数据管理系统：游戏内访问数据（`GameDB`）
- [x] log 文本：控制台只输出导表结果与失败原因；导表记录/过程/失败原因写入日志文件
- [x] 数据目录下文件变更时，同步更新数据树
- [x] 点击数据树下的 JSON 文件，可视化预览（只读）
- [x] 表格视图：行号列 + 表头「字段名」+ 列顺序与原表相同
- [x] 游戏代码（`runtime/`）与工具代码（`data_tools/`）分离，导出时排除工具代码
- [x] 导表面板：选择 CSV 后，底部预览该表数据（真实字段名）
- [x] 导表面板：表在导出目录已有同名 JSON 时，显示提示文字

**验收标准**

- [x] 在 Dock 选择 CSV 与导出路径后点「导表」，生成 `{导出路径}/{表名}.json`
- [x] 控制台只打印导表结果；失败时打印失败原因
- [x] 日志文件记录导表过程与失败原因
- [x] 游戏内 `GameDB.get_table("表名")` 可取到导出数据
- [x] 数据目录下 JSON 文件新增/删除/修改时，数据树自动刷新
- [x] 点击数据树中的 JSON 文件，显示可读的表格预览（只读）
- [x] 预览表格左侧有行号列（1、2、3…），字段列按原 CSV 字段顺序排列
- [x] 表头显示「字段名」，如 `name`、`price`、`tags`（导出 JSON 无独立列名，仅字段名，故以字段名作为列名）
- [x] 选择 CSV 后，导表面板底部显示该表预览（行号、key、字段名列）
- [x] 导出目录已存在同名 JSON 时，显示「已存在同名 JSON」提示

**涉及文件**

- `addons/yukys_kits/data_tools/`（编辑器工具代码，导出时排除）
- `addons/yukys_kits/runtime/`（游戏代码，随游戏导出）
- `addons/yukys_kits/plugin.gd`
- `project.godot`（autoload 调整）

**实现备注**

> 参考 `D:\Project\Godot\3d俄罗斯方块` 的 `excel_import_tool`，命名与实现做了优化：
> 用 `JSON.stringify/parse` 替代手工拼接 JSON；补全文件/空值校验；统一 `{ok, error/data}` 结果模式；新增日志系统。

**状态更新记录**

- `2026-09-08`：创建并完成实现
- `2026-09-08`：新增「数据目录变更自动刷新数据树」「JSON 可视化预览（只读）」两项子功能
- `2026-09-08`：预览表格增强——新增行号列、表头显示「字段名」、列顺序与原表一致（因导出 JSON 无独立列名，仅字段名，表头从「字段名(类型)」改为「字段名」）
- `2026-09-09`：游戏代码与工具代码分离——运行时（`GameDB`/`json_data_tool`）移到 `runtime/`，`DataImporter` 改为编辑器专用实例（plugin.gd 创建并注入，非 autoload），导出时排除工具代码
- `2026-09-10`：导表面板新增「选择 CSV 后底部预览（真实字段名）」与「同名 JSON 重复提醒」；子表（多表）方案撤回，恢复单表导表
- `2026-09-12`：`GameDB` 数据库路径改为从 ProjectSettings（键 `addons/yukys_kits/data_dir`，缺省 `res://data`）读取，不再写死；编辑器 `DataImporter` 在用户设置导出路径时同步写入该键

**功能描述**

> 更新 `GameDB`，新增 `load_sprite` / `load_audio` / `load_resource` 等方法，通过路径从资源库加载外部导入资源（图片、音频），加载结果缓存；按「资源加载器 → 全局化路径 → exe 相对路径」依次回退，解决导出后 `res://` 路径变化的问题。
